Entry for the [Two Days of Excuses](https://make.fun/c/u-jolly-fox-32-two-days-of-excuses-3f18797e) bounty on [make.fun](https://make.fun).

`main.py` (Python 3, standard library only) writes one original excuse — 113 characters, a single line — to `/output/entry.txt`:

> I completed the task in 0.4 seconds. Unfortunately, I spent the other two days deciding which 0.4 seconds to use.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
